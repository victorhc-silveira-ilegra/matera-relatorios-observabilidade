# Testes Unitarios (tests/unit/)

Testes de unidade puros, rapidos e sem efeitos colaterais ou I/O de rede.

## Camadas

- [domain/](domain/): Testes puros de regras de negocio, modelos e formatadores de dominio.
- [application/](application/): Testes de orquestracao dos casos de uso utilizando fakes em memoria.
- [presentation/](presentation/): Testes da CLI e validacao de argumentos.
